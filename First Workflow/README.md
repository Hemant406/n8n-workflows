# 🎯 Customer Feedback & Automated Discount System

An automated customer feedback workflow built using **n8n** that collects customer information through a form, provides discounts to customers who submit positive feedback, and stores all customer data in Google Sheets.

This workflow helps businesses automate customer feedback collection and reward satisfied customers.

---

## 📌 About the Workflow

Collecting customer feedback and managing discounts manually can be time-consuming.

This workflow automates the entire process using n8n.

Whenever a customer submits the feedback form, the workflow:

- Collects customer details through an n8n Form Submission node.
- Checks the customer's feedback.
- Identifies customers who have provided positive feedback.
- Assigns a discount to customers with positive feedback.
- Stores customer information and feedback details in Google Sheets.

---

## ⚙️ Workflow Architecture

The workflow follows these steps:

1. **Form Submission:** Uses the n8n Form Trigger node to collect customer details and feedback.
2. **Feedback Evaluation:** Checks whether the submitted feedback is positive.
3. **Discount Assignment:** Provides a discount to customers who submit positive feedback.
4. **Google Sheets Integration:** Saves customer details, feedback, and discount information in Google Sheets.

## 🚀 How to Use This Workflow

### 1. Import the Workflow

1. Download the workflow JSON file from this folder.
2. Open your n8n dashboard.
3. Click the three-dot menu.
4. Select **Import from File**.
5. Upload the downloaded JSON file.

### 2. Configure the Form Submission Node

Configure the n8n Form Trigger node with the required customer fields, such as:

- Customer Name
- Email Address
- Customer Feedback

You can customize the form fields according to your requirements.

### 3. Configure Feedback Evaluation

Check the feedback submitted by the customer.

The workflow identifies whether the feedback is positive and decides whether the customer qualifies for a discount.

### 4. Configure Google Sheets

- Connect your Google account to n8n.
- Select the required Google Spreadsheet.
- Configure the Google Sheets node.
- Map the customer details and feedback fields to the appropriate spreadsheet columns.

### 5. Execute the Workflow

1. Save the workflow.
2. Open the form generated by the Form Trigger node.
3. Submit sample customer information.
4. Check whether the discount is assigned correctly.
5. Verify that the customer data is saved in Google Sheets.
